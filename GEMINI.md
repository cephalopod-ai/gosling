## Authority

`AGENTS.md` is the canonical repo-local operating contract. This file is an
adapter and defers to it for every rule governing required read order, authority,
documentation patches, validation expectations, and logging. Where this file and
`AGENTS.md` disagree, `AGENTS.md` wins.

Read `AGENTS.md` first and in full, then return here for any Gemini-specific
deviation.

## Gemini-specific deviations

None currently apply. Gemini agents follow `AGENTS.md` unchanged, including its
required execution clauses and its documentation and agent operating contract.

Record a deviation here only when Gemini's behaviour genuinely differs from the
contract in `AGENTS.md`. Do not restate rules that already live there: a second
copy drifts from the original and creates exactly the ambiguity this adapter
exists to prevent.
